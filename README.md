## Introduction

`xbot.plugins.docker` provides Docker support for [xbot.framework](https://github.com/zhaowcheng/xbot.framework).

## Installation

Install via pip:

```
pip install xbot.plugins.docker
```

## Getting Started

```python
from xbot.plugins.docker.docker import DockerConnection
```
